# SWEAT440 | December 2026 Creative

Presentation website. Open the Railway link, enter the password, click through.

- Arrow keys, click or swipe to change slides. Full screen button at the bottom.
- Videos play automatically on their slide; tap the speaker button for sound.
- Password: set `SITE_PASSWORD` in Railway → Variables (any username works).
- Start command: `npm start` (Railway detects this on its own).
